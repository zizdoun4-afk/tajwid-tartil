# PHASE 5 — ADVANCED VOICE & RAFIQ

Only now improve the voice intelligence layer.

## IMPORTANT

The existing acoustic analyzer is NOT speech recognition.

Do not pretend it can verify Quran words.

### Level 1 — Acoustic Guidance

Keep:

* pacing
* pauses
* energy stability
* recording quality

Present results honestly.

### Level 2 — Recitation Alignment

If technically feasible, implement real alignment against the known Quran text.

Potential capabilities:

* detect likely missing words
* detect likely repeated words
* detect ayah position
* estimate where the user deviated

Every result must be presented as:

**Possible mismatch**

not:

**Your Quran recitation is wrong.**

### Level 3 — Tajwid Assistance

Only implement if technically reliable.

Potential feedback:

* possible prolongation issue
* possible pause issue
* possible pronunciation area to review

Never issue definitive religious judgments.

## Privacy

Voice analysis should preferably happen locally.

If external processing is ever introduced:

* make it explicit
* obtain user consent
* explain data handling
* provide an offline alternative where possible
